# Contributing

1. Read PROJECT_CHARTER.md, AGENTS.md and docs/RESEARCH_PROTOCOL.md.
2. Give each material claim a stable ID and exact source locus.
3. Separate source content from historical interpretation.
4. Record contrary evidence and competing explanations.
5. Preserve UNKNOWN where evidence does not permit a conclusion.
6. Do not copy complete copyrighted books or translations.
7. Run the register validator before proposing a change.
8. Do not close a case merely because a familiar narrative has been repeated; apply the quality gates.
