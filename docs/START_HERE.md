# Start here

1. Read the project charter and AGENTS.md.
2. Read the research protocol and claim/evidence policy.
3. Read the terminology policy and source criticism checklist.
4. Open docs/RESEARCH_PROGRESS.md for the current evidence state.
5. For a case, begin with its CASE.md and open-questions file.
6. Before adding a historical statement, create or update the source and claim records.
7. Run python tools/validate_research_data.py.
8. Keep primary-text inspection, secondary scholarship and inference visibly separate.
