# تحقيق التاريخ السياسي والعسكري المبكر للدولة الإسلامية (629–661م)

مشروع تحقيق تاريخي نقدي متعدد المصادر لإعادة بناء الأحداث العسكرية والسياسية المرتبطة بانتقال سلطة الدولة الإسلامية الناشئة خارج الجزيرة العربية. لا يفترض المشروع مسبقاً أن الحملات كانت دفاعاً محضاً أو توسعاً محضاً؛ بل يختبر كل تفسير على مستوى الحالة والأدلة.

## المنهج

- المصدر شاهد يُفحص، وليس سلطة تُسلَّم بها.
- افصل بين الحدث والرواية والتفسير والفرضية.
- لا تستنتج النية من النتيجة وحدها.
- لا تفترض استقلال مصدرين لمجرد اختلاف اسميهما.
- سجّل الأدلة المضادة وحدود المعرفة.
- استخدم مصطلحات وصفية، واجعل ألفاظ `فتح` و`غزو` و`احتلال` موضوعاً للتحليل لا حكماً مسبقاً.

## الحالة

هذا المستودع بدأ حديثاً. ستُضاف إليه وثائق الميثاق والمنهج وسجلات المصادر والادعاءات ودراسات الحالات على فرع تأسيسي مستقل. لا توجد نتائج تاريخية نهائية بعد.

## نطاق المشروع

النطاق الأساسي 629–661م، مع الرجوع إلى السياقات السابقة أو متابعة النتائج اللاحقة عند الحاجة، وتوضيح سبب كل امتداد.

## البداية

راجع `PROJECT_CHARTER.md` و`AGENTS.md` و`docs/RESEARCH_PROTOCOL.md` و`docs/CLAIM_AND_EVIDENCE_POLICY.md` قبل إضافة أي ادعاء. لا تنقل أي معلومة من الروايات أو الذاكرة إلى مرتبة الحقيقة دون تحديد المصدر والموضع ونقد الاستقلال.
