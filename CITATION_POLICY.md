# Citation policy

- Cite the edition or translation actually inspected, not merely an author's name.
- Record page, chapter, report number, folio, line or inscription identifier whenever possible.
- Distinguish primary text, editor's apparatus, translation and modern interpretation.
- Prefer DOI, publisher page, university repository or stable catalogue record.
- A search snippet is a discovery aid, not adequate proof for a material conclusion.
- If only an abstract, excerpt or OCR was checked, state that limitation explicitly.
- Keep quotations proportionate and do not upload copyrighted books or modern translations.
- Record access date and any OCR/translation uncertainty.
